# FCM Sender

Страница для отправки push-уведомлений через Firebase Cloud Messaging. Один HTML-файл, сервер не нужен.

## Как отправить уведомление

1. Откройте `fcm-sender.html` двойным кликом.
2. Добавьте ключ сервисного аккаунта (`service-account.json`): кнопкой «Выбрать файл…», перетаскиванием или вставкой (⌘V).
3. Выберите получателя: **Топик** (по умолчанию `all`) или **Токен устройства**.
4. Заполните заголовок и текст, нажмите «Отправить».

Ключ хранится только в памяти вкладки и пропадает при её закрытии или перезагрузке.

> Для проверки отправляйте на токен своего устройства: уведомление на топик `all` получат все пользователи.

## Безопасность

Используйте ключ только с правами на FCM — ключ `firebase-adminsdk-…` даёт полный доступ к проекту. Как создать:

1. [Google Cloud Console](https://console.cloud.google.com/iam-admin/serviceaccounts) → **Service Accounts → Create service account**.
2. Роль — **Firebase Cloud Messaging API Admin**.
3. В созданном аккаунте: **Keys → Add key → Create new key → JSON**.

Закончив, закройте вкладку или нажмите «Убрать».

## Возможные ошибки

| Сообщение | Причина |
| --- | --- |
| `Invalid JWT Signature` | Ключ отозван или удалён |
| `Token must be a short-lived token…` | Неверное системное время на компьютере |
| `PERMISSION_DENIED` | У аккаунта нет роли на FCM |
| `UNREGISTERED` | Токен устройства устарел |
| `SENDER_ID_MISMATCH` | Токен из другого Firebase-проекта |

## Разработка

Исходники — в `web/`. После правок пересоберите `fcm-sender.html`:

```bash
npm install
npm run build
```

`npm run dev` — dev-сервер с автообновлением.
